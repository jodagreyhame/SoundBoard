# SoundBoard

A Windows soundboard that mixes clips over your live microphone, so other people in a
voice call hear them as if you had said them.

This is a historical revision of this file. Its content has been replaced: earlier
revisions documented a bundled clip library that is no longer part of this project.
No audio ships with SoundBoard - the `sounds/` folder is user-supplied.

See the README at the tip of the branch for current documentation.
